# Portfolio

One long page: showreel videos, about me, projects grid (one featured), skills and contact.

Edit the content at the top of the script in `index.html`:
- `SITE`: name, role, "looking for" text, about paragraphs, email, links, skills
- `VIDEOS`: showreel videos (YouTube ID or an mp4 in `videos/`)
- `PROJECTS`: one block per project; `featured: true` makes it the large one

Images go in `images/` (lowercase names):
- `background.png` (desktop background), `frame-top.png` and `frame-side.png` (the window frame), `me.png` (optional portrait), `cursor.png` (optional cursor)
- `projN-thumb.png` for each project card, plus any screenshots used in the case studies

Put `resume.pdf` next to `index.html`.

Videos go in `videos/` (lowercase), for example `videos/showreel.mp4`; list them in `VIDEOS` in `index.html`.
